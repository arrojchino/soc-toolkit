# soc-toolkit

Four standalone tools. One job each.

- [signal](https://github.com/arrojchino/signal) - alerts and findings, one view
- [atlas](https://github.com/arrojchino/atlas) - search across a 55-repo knowledge base
- [ward](https://github.com/arrojchino/ward) - read-only local utilities
- [trace](https://github.com/arrojchino/trace) - evidence reports from analysis JSON

No duplicated code here. Each tool lives in its own repository.
